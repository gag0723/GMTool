密码工具百宝箱 · 本地版（Windows x64 独立运行包）
==================================================

一、运行
  1. 解压本目录到任意位置（路径建议不要包含中文空格以外的特殊字符）。
  2. 双击 start.bat。
  3. 浏览器会自动打开 http://127.0.0.1:18080/（局域网内其他电脑可用 http://<本机IP>:18080/）。

二、说明
  - 本包内置 Python 3.13 运行环境与全部依赖，无需安装任何其他软件。
  - 所有工具模块的计算全部在本机完成，不访问外部网络、无广告、无授权校验。
  - 本地 CA 等运行期数据保存在 data\ 目录。
  - 修改端口：右键编辑 start.bat，改第一处 set CIPHERBOX_PORT=18080 即可
    （也可在启动前于命令行执行 set CIPHERBOX_PORT=9090 再运行 start.bat）。

三、退出
  在 start.bat 的命令行窗口按 Ctrl+C，或直接关闭窗口。

四、常见问题
  - 双击后窗口一闪而过：把 start.bat 拖到命令行里运行，可看到具体报错。
  - 端口被占用：换一个 CIPHERBOX_PORT 后重试。
  - 杀毒软件拦截：本包不含任何远程通信代码，可加入白名单。
